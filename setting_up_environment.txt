SETTING UP ENVIRONMENT (single source of truth)
Last updated: 2026-07-10

IMPORTANT RULE
- If setup/install/train commands change, update this file in the SAME commit.

==================================================
0) PRE-REQ
==================================================
- OS: Linux/macOS
- Python: 3.10-3.12 recommended
- GPU: CUDA environment for torch==2.2.2 if training on GPU
- Disk: at least 40 GB free recommended

==================================================
1) CLONE
==================================================
git clone https://github.com/kwskws1998/aiffel.git
cd aiffel

python3 -m venv .venv
source .venv/bin/activate
python -V

The venv commands above are for local use. On a rented GPU, skip them and use
scripts/setup_distilbert_conda_cloud.sh in section 4.

2) ONE-SHOT INSTALL (recommended)
==================================================

IMPORTANT:
- The command above contains the verified project bundle ID and SHA256. Replace
  both only when intentionally using a different authorized bundle.
- Never export a literal placeholder such as <Google-Drive-file-id>.
- Do not run Conda and .venv simultaneously. If the prompt shows both, run:

    hash -r
    conda activate va_gaze
    export PYTHON_BIN="$CONDA_PREFIX/bin/python"

  "Anyone with the link" or use permitted local TSV files in
  data/external_english with DATA_ZIP_FILE_ID and DATA_ZIP_URL unset.

4) TRAINING COMMANDS
==================================================
DistilBERT setup and matrix runner:
DATA_ZIP_FILE_ID="1xXM32nva_4I3EAVAOrQ84L16f-LjsJbj" \

Cloud NVIDIA GPU with Conda:
DATA_ZIP_FILE_ID="1xXM32nva_4I3EAVAOrQ84L16f-LjsJbj" \
DATA_ZIP_SHA256="5db750ededfd9717dcca465b34fd7e6c348e50e563ad2c0814c458b04441e81d" \
bash scripts/setup_distilbert_conda_cloud.sh

Four RTX 5090 GPUs with Conda, CUDA 12.8 PyTorch, ET2, and no-IEMOCAP data:
bash scripts/setup_xlmr_5090_conda_cloud.sh

The RTX 5090 script uses PyTorch 2.7.1 with the official cu128 wheel because
the general torch==2.2.2/cu121 environment does not support Blackwell sm_120.
It verifies four GPUs and preloads xlm-roberta-large and roberta-base once
before the four fold processes start.

For two seeds with one fold per GPU, use this assignment:
- GPU 0: seed 42, fold 1
- GPU 1: seed 42, fold 2
- GPU 2: seed 43, fold 1
- GPU 3: seed 43, fold 2

Use the same --run-id and --preds-dir within a seed, and different values
between seeds. For XLM-R-large postfix batch 16 on RTX 5090, include:
  --batch-size 16 --gradient-accumulation-steps 1 \
  --bf16 --gradient-checkpointing

Do not set SKIP_DEPS=1 yourself on a fresh Conda environment. The cloud script
installs numpy, pandas, PyTorch, Transformers, gdown, and the remaining pinned
requirements before calling install.sh.

==================================================
7) TROUBLESHOOTING
==================================================
- ModuleNotFoundError after install:
  - Ensure venv is active: source .venv/bin/activate
  - Reinstall: pip install -r requirements.txt

- ET2 checkpoint not found:
  - Re-run: python setup_et_models.py --skip-install --skip-et1 --et2-checkpoint ./checkpoints/et_predictor2_seed123

- Missing data files:
  - Re-run: python prepare_english_data.py --output-dir data --seed 42 --force

- W&B prompt blocks training:
  - Disable online sync: export WANDB_MODE=offline

- No space left on device:
  - Use: --save-total-limit 1
  - Optionally disable periodic checkpoints: --save-strategy no
